# WON 아일랜드

**우리은행 아이디어 경진대회 제안 프로젝트**

금융 사기 대응을 게임으로 연습하고, 우리틴틴의 용돈 관리 경험과 연결하는 금융교육 서비스 아이디어입니다.

## 기획 개요

- **대상:** 만 7~18세 이용자와 부모
- **핵심 경험:** 가상 가게를 운영하면서 정상 거래와 사기 상황을 구분하고, 공식 경로 확인·거절·도움 요청을 연습
- **부모 참여:** 학습 주제 설정, 추가 교육 보상 설계, 학습 리포트를 통한 대화
- **게임 구성:** 오전 교역·위험 탐지와 오후 매장 운영을 연결한 경영 시뮬레이션

## 제안서

[WON 아일랜드 제안서 — 화면 목업 6개 포함 (PDF, 5페이지)](WON_Island_proposal_with_6_screens.pdf)

문제 정의, 서비스 소개, 상세 기능, 게임 흐름, 기대효과와 평가 가정을 담았습니다.

## 진행 범위

서비스 기획 및 화면 목업 단계의 제안입니다. AI 에이전트, 실제 예치·송금, 부모 앱 자동 리포트 등은 제안 기능이며, 교육 효과와 사업 효과는 검증 대상입니다. 이 폴더에는 제안서와 소개 문서를 포함합니다.
