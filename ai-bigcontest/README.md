# 사회적 고립 예방을 위한 활동 저조 공간 분석과 생활권 자원 연계

[확실] 2026 빅콘테스트 프로젝트의 분석 코드와 기존 실행 검증 기록을 정리한 포트폴리오입니다. 강남구·춘천시, 2025년 7~12월, 20·30·40·50·60대 이상 격자·연령 집단을 다룹니다. 실제 업로드된 최종 제출 파일과의 동일성은 별도 확인이 필요합니다.

## 해결하려는 문제와 분석 흐름

[추정] 행정 담당자가 활동 저조 공간을 우선 점검하고, 접근성 부족과 기존 자원의 이용장벽을 나눠 검토하도록 돕는 접근입니다. 시설을 늘리는 단일 해법 대신 지역의 위험 신호와 생활권 자원을 연결합니다.

| 단계 | 실제 코드의 역할 |
|---|---|
| Step0 | 환경·인구·유동 자료를 결합해 월별·연령별 활동 잔차와 선별 결과 생성 |
| Step1 | 시설 규모와 소비 자료 등을 이용한 시설 질량 M 구성 |
| Step2 | 시설 질량과 거리로 중력 기반 접근성 X 계산 |
| Step3 | 활동 저조 선정 상태의 첫 진입을 생존 사건으로 정의 |
| Step4 | α 보정·AFT 학습·검증·확률 계산 |
| Step5 | 조건부 잔여시간과 위험 우선순위, 가상 인프라 변화 시나리오 |
| Step6 | 대응 유형·거점 후보·조건부 서비스 연결·예방 개입 카드 |

[확실] 포함된 Step5 검증 기록의 모델 사양은 연령별 5개 pooled 모델, 공통 5개 인프라 X와 지역 지시변수입니다. 구버전의 지역×연령별 개별 모델 설명과 혼동하지 않아야 합니다.

## 증명하는 범위와 해석의 한계

[확실] 기존 기록에는 replay 모드에서 코드 셀 43개 통과가 남아 있습니다. Step0~3의 기존 전처리·기준 입력을 재사용하고 Step4 이후를 재계산한 기록입니다. 이번 공개용 정리에서 분석을 다시 실행하지 않았습니다.

[확실] 사건은 개인의 사회적 고립 확진이 아니라 활동 저조 선정 상태의 첫 진입입니다. 검증은 미래 시점의 실제 고립 결과를 확인한 실험이 아닙니다. 인프라 시나리오는 모델 민감도이며 실제 정책 개입의 인과효과가 아닙니다. LLM/API 호출이 없는 규칙 기반 설계·시연 코드가 포함되어 있습니다.

## 실행

[확실] Python 3.11 환경의 기존 작업물을 정리했습니다. `python -m pip install -r requirements.txt` 후 Jupyter에서 통합 노트북을 열 수 있습니다. 버전 고정 환경은 복원하지 않았으며 새 환경에서 전체 재현을 보장하지 않습니다.

[확실] 공개용 사본의 개인 경로는 `private_inputs`로 변경했습니다. 통합 노트북 설정 셀의 MAIN·WORK와 단계별 경로를 보유한 데이터 위치에 맞춰 지정해야 합니다. replay에는 기존 전처리·기준 결과가, rebuild에는 원자료·공간 자료가 필요합니다. 폴더 구조는 코드 내 CFG·raw_folders·파일 검사 부분을 참고하세요. 원자료 없이 바로 실행되는 데모가 아닙니다.

[확실] PDF 카드에는 reportlab과 한글 TrueType 폰트가 필요합니다. Windows 기본 폰트가 없는 환경에서는 폰트 경로를 수정하거나 `RUN_PDF=False`로 설정하세요.

## 데이터 및 공개 범위

[확실] 통신·카드 원자료, 상세 격자별 결과, 지도 HTML에 내장된 데이터, 원본 발표자료는 포함하지 않았습니다. 노트북 출력과 첨부 이미지도 제거했습니다. `evidence`에는 기존 실행 상태·수식 점검 등의 요약 기록만 담았습니다.

[불확실] 대회 약관상 코드·파생 결과의 공개 허용 범위는 이 묶음에서 확인되지 않았습니다. 데이터 제공기관의 재배포 허가나 오픈소스 라이선스를 부여한 자료가 아닙니다. 공개 전에 참가 약관과 팀 합의를 확인해야 합니다.

[모름] 개인별 기여 범위와 실제 제출 완료·수상 여부를 증명하는 접수증은 포함 자료에서 확인하지 못했습니다. 개인 역할이나 수상 실적을 임의로 기재하지 않았습니다.
