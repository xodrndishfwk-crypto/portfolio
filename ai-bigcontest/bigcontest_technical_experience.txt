빅콘테스트 사회적 고립 예방 프로젝트 — 기술 구현 및 문제 해결 경험

1. 프로젝트 개요

우리 팀은 통신 유동인구, 카드 소비, 건물 공간정보, 주민등록 인구, 공공·생활 인프라 데이터를 결합해 활동이 저조한 공간을 찾고, 해당 공간을 실제 지원 거점과 서비스 후보로 연결하는 분석 파이프라인을 개발했다. 강남구와 춘천시의 2025년 7~12월 자료를 대상으로 50m 격자와 연령 집단을 분석 단위로 사용했다.

기술적으로는 서로 다른 데이터의 공간·시간 기준을 맞추는 작업, 지역 환경을 고려한 활동 저조 탐색, 시설 접근성 모델링, 구간 중도절단 생존분석, 공간 단위 모델 검증, 모델 결과와 실제 시설의 연결에 집중했다. 예측 점수만 출력하는 대신 담당자가 어떤 공간을 먼저 확인하고 어떤 자원을 검토할 수 있는지까지 이어지는 구조를 구현했다.

아래의 문제 해결 내용은 구현 코드와 기존 실행 기록에서 확인되는 처리와 검증을 중심으로 정리했다. 실제로 발생한 오류와 사전에 고려한 데이터·모델링 위험은 구분해서 기술했다.

2. GIS 데이터 통합: 좌표와 결합 기준이 다른 자료의 정합성 확보

기술적 과제
통신 자료는 격자와 좌표, 주민등록 자료는 행정동, 시설 자료는 개별 지점, 건물 자료는 폴리곤을 기준으로 구성되어 있었다. 파일 형식과 공간 단위가 서로 달라 단순히 행정동명이나 격자 코드만으로 결합하면 다른 공간이 연결되거나 한 행이 여러 행으로 늘어나는 문제가 생길 수 있었다.

적용 기술과 처리
GeoPandas, Pyogrio, Shapely를 이용해 공간 데이터를 처리하고, 거리·면적 계산 기준을 미터 단위의 EPSG:5179로 통일했다. 격자 중심점을 기준으로 50m 사각형을 재구성하고 행정동 경계와 공간 결합했다. 경계에 걸려 복수 행정동에 연결되는 격자와 분석 지역 밖 격자는 별도 상태로 분리했다.

표 결합에는 pandas의 one_to_one, many_to_one 관계 검증을 적용했다. 월·격자 코드·좌표와 GRID_ID를 이용해 공간을 추적하고, 같은 월과 좌표에 여러 코드가 존재하는 경우에는 오류 자료를 저장한 뒤 처리를 중단하도록 구성했다.

확인한 결과와 의미
중복 키, 비정상 좌표, 잘못된 결합 관계를 후속 모델 학습 전에 확인할 수 있는 구조를 만들었다. 분석 결과가 이상할 때 모델만 수정하는 대신 입력 자료와 결합 과정을 추적할 수 있도록 했다.

3. 비교 집단 기반 이상 탐색: 유동인구가 적은 공간과 환경 대비 활동이 저조한 공간 구분

기술적 과제
유동인구가 적다는 사실만으로 해당 공간을 위험하다고 판단하기 어려웠다. 주거 규모가 작거나 상업시설이 적은 공간은 원래 유동량이 낮을 수 있어, 절대 활동량 순위에는 지역 환경의 차이가 섞이기 때문이다.

적용 기술과 처리
건물과 격자가 겹치는 면적에 따라 건물 연면적을 배분하고, 주거 연면적·전체 연면적·공동주택 비중·상업 비중·주거 비중·행정동 인구·연령 구성을 비교 변수로 만들었다. 건물 하나가 여러 격자에 걸쳐 있을 때 전체 연면적을 각 격자에 중복 집계하지 않도록 했다.

지역·월·연령별로 환경 변수를 표준화한 뒤 SciPy cKDTree로 환경이 유사한 격자를 최대 50개 탐색했다. 지리적 거리순이 아니라 환경 특성의 유사성을 기준으로 비교 집단을 구성하고 자기 자신은 제외했다. 비교 집단의 유동인구 중앙값과 해당 격자의 유동인구에 로그 변환을 적용해 활동 잔차를 계산했다.

검증과 예외 처리
비교 집단이 충분하지 않거나 건물 속성의 확인 비중이 낮은 격자는 별도 사유로 제외했다. 비교 대상과의 환경상 거리가 큰 격자는 검토 대상으로 표시했다. 활동 잔차와 공간 ID로 정렬 순서를 고정하고, 월별 선정 수가 설정 비율에 맞는지도 검사했다.

확인한 결과와 의미
단순 저유동 지역 목록이 아니라 유사한 환경의 공간에 비해 활동이 적은 격자를 탐색하는 체계를 구현했다. 다만 이 결과는 개인 고립 진단이 아니라 공간 단위 상대적 선별 신호로 사용했다.

4. 시설 가중치 설계: 자료에 없는 시설 이용량을 실제 관측값처럼 다루지 않기

기술적 과제
시설 개수만으로는 생활권 자원의 차이를 표현하기 어렵지만, 모든 시설의 실제 이용객 수나 개별 매장 결제를 확보할 수도 없었다. 특히 무료 공원이나 주민센터의 이용 정도를 특정 카드 업종 결제로 직접 대체하면 해석이 과도해질 수 있었다.

적용 기술과 처리
시설 유형별 카드 업종을 연결하는 초기 방식과, 시설 주변 카페 공급에 지역·연령별 소비 특성을 결합하는 수정 방식을 구현했다. 수정 방식에서는 반경 100m·300m·500m 내 카페를 탐색하고 기본 반경을 300m로 설정했다. 거리가 가까운 카페의 기여도를 높이고, 지역별 카페당 평균 소비금액·소비건수와 결합해 시설 주변 환경을 나타내는 대리변수를 구성했다.

시설 주변에 카페가 없다는 이유만으로 시설의 가중치가 0이 되지 않도록 기본 질량을 두었다. 시설이 카페인 경우 자기 자신을 주변 카페에서 제외하고, 좌표 확인이 필요한 시설은 정상 시설과 분리했다. 이전 방식의 결과는 별도 파일과 컬럼에 보존해 변경 전후의 계산 근거를 추적할 수 있게 했다.

검증과 해석 관리
반경별 순위 상관을 계산해 반경 선택에 대한 민감도를 살폈다. 시설 질량이 양수이고 정규화 후 평균이 1인지 검사했으며, 지역 경계 인근에서 카페 공급이 누락될 가능성을 표시했다.

이 값은 시설 주변의 실제 매출이나 시설별 서비스 품질을 측정한 결과로 설명하지 않았다. 관측한 카페 위치와 지역 소비를 결합한 모델 입력이라는 점을 분명히 했다.

5. 거리 기반 모델링과 연산 최적화: 대규모 격자·시설 조합의 접근성 계산

기술적 과제
격자와 시설이 많아질수록 모든 조합의 거리를 계산하는 비용이 증가했다. 동시에 시설과 격자가 같은 위치에 있으면 역거리 계산이 불안정해지고, 시설 자료가 없는 상태를 접근성 0으로 처리하면 결측과 실제 부족이 섞일 수 있었다.

적용 기술과 처리
시설 질량과 거리 제곱의 역수를 결합해 중력 기반 접근성을 계산했다. SciPy cdist와 NumPy 행렬 연산을 활용하고, 격자를 일정 크기로 나눠 처리해 한 번에 생성하는 거리행렬의 크기를 제한했다. 시설 주변 탐색에는 cKDTree의 반경 질의를 사용했다.

거리 하한은 1m로 설정해 동일 좌표에서 값이 발산하지 않도록 했다. 원시 접근성에는 로그 변환과 정규화를 적용하고, 이후 보정과 시나리오에서도 같은 정규화 기준을 재사용했다. 시설 유형의 자료가 없는 경우는 결측 상태로 보존했다.

확인한 결과와 의미
접근성 계산을 반복 가능한 행렬 연산으로 구성하고, 동일한 거리와 변환 기준을 후속 분석까지 유지했다. 계산된 거리는 직선거리이며 도보 경로나 실제 이동시간과 구분했다.

6. 모델 개선 실험: 주변 활동 특성을 반영하는 α 보정과 후보 비교

기술적 과제
기본 시설 질량과 거리만으로 만든 접근성은 시설 주변의 시간대·요일별 활동 차이를 충분히 표현하지 못했다. 반면 활동량이 높은 곳에 무조건 큰 가중치를 주는 방식도 데이터로 검증하지 않은 가정이 될 수 있었다.

적용 기술과 처리
7월의 연령별 유동인구, 카드 소비 시간대 비중으로 가중한 주변 유동, 평일·주말 소비 특성으로 가중한 주변 유동을 결합해 시설별 활동 보정 점수를 만들었다. 로그 변환·표준화·극단값 제한을 적용하고, 지수 변환을 통해 양수인 α를 생성했다.

지역·시설 유형·연령별 α 평균을 1로 맞춰 전체 시설 가중치를 일괄 확대하는 효과와 상대적인 재배분 효과를 구분했다. 보정 반경 300m·800m와 음수·양수 강도를 비교하고, 무보정 모델을 포함해 총 13개 후보를 평가했다.

확인한 결과와 의미
검증 자료의 연령별 평균 구간 음의 로그우도를 기준으로 반경 800m, 강도 -1 후보를 선택했다. 주변 활동이 높을수록 가중치를 높여야 한다는 방향을 미리 정답으로 고정하지 않고 반대 방향까지 비교한 실험이었다.

음의 보정이 선택됐다는 사실은 해당 자료와 모델에서 그 보정이 평가 기준에 유리했다는 의미로 해석했다. 시설의 품질이나 실제 정책 효과가 확인됐다는 의미로 확장하지 않았다.

7. 생존분석 라벨링: 월별 관측 공백과 사건 시점의 불확실성 처리

기술적 과제
월별 데이터에서는 활동 저조 상태로 바뀐 정확한 날짜를 알 수 없었다. 또한 관측되지 않은 달을 정상 상태로 간주하거나, 자료가 누락된 뒤 추적을 이어 붙이면 사건 발생 시점이 잘못 정의될 수 있었다.

적용 기술과 처리
7월에 활동 저조로 선정되지 않은 격자·연령 집단을 기준 집단으로 두고 이후 처음 선정되는 시점을 추적했다. 사건이 발생한 정확한 날짜 대신 직전 관측월과 최초 선정월 사이의 구간을 라벨로 구성했다. 관측기간 끝까지 사건이 없으면 우측 중도절단으로 처리했다.

기준월부터 선정된 집단, 기준월이 누락된 집단, 후속 관측이 없는 집단을 구분했다. 관측 도중 결측이 발생하면 마지막 연속 관측 시점에서 추적을 중단하고, 이후 자료가 다시 나타나도 기존 추적을 재개하지 않았다.

검증과 의미
라벨 생성 함수에 최초월 사건·마지막월 사건·관측 종료·기준월 누락·중간 결측 등 8개 합성 사례를 적용하는 검사를 구현했다. 완전 관측 자료에서는 별도의 벡터화 계산으로 사건 여부와 최초 진입 시점을 다시 산출해 순차 추적 결과와 비교했다.

결측을 사건 미발생으로 바꾸지 않고 관측 가능한 범위에 맞춰 학습 자료를 구성했다는 점이 핵심이다.

8. Weibull AFT 직접 구현: 수치 불안정과 최적화 상태 점검

기술적 과제
구간 중도절단 자료를 일반적인 이진 분류로 처리하면 사건 시점 정보를 잃게 된다. 생존모델에서도 작은 확률 차이, 큰 지수값, 설명변수의 단위 차이 때문에 우도와 기울기 계산이 불안정해질 수 있었다.

적용 기술과 처리
구간 중도절단 Weibull AFT를 적용하고, SciPy를 이용한 최대우도 목적함수와 분석적 기울기를 구현했다. 설명변수는 내부 표준화를 거치고 shape는 양수가 되도록 매개변수화했다. 작은 확률 차이와 지수 계산에는 expm1, logaddexp, 계산 범위 제한 등을 활용했다.

최적화 결과는 반환 여부만 확인하지 않고 목적함수의 유한값과 최종 기울기 크기를 점검했다. 기본 AFT 적합 함수에는 복수 초기값 시도, 정보행렬 확인, 계수·공분산의 원래 스케일 변환도 포함했다. 분석적 기울기를 수치 기울기와 비교하고 알려진 계수의 합성 생존자료를 복원하는 검사도 구현했다.

구현 범위
최종 α 후보 비교는 직접 구현한 우도와 기울기를 활용했다. 기본 적합 함수에 포함된 모든 검사와 최종 후보 탐색이 동일한 실행 경로는 아니므로, 검사 코드의 존재와 실제 실행 검증 범위를 구분했다.

9. 공간 데이터 모델 평가: 가까운 지역이 학습과 평가에 섞이는 위험 완화

기술적 과제
인접 격자는 생활환경과 시설 접근성이 유사하다. 개별 행을 무작위로 나누면 가까운 공간이 학습과 테스트에 동시에 포함되어 일반화 성능을 낙관적으로 평가할 수 있었다.

적용 기술과 처리
500m 공간 셀을 분할 단위로 사용했다. 지역과 공간 셀로 고정 키를 만들고 SHA-256 기반 규칙으로 학습·검증·테스트에 약 60:20:20으로 배정했다. 같은 공간 셀은 모든 연령에서 동일한 분할에 속하게 했다.

학습 자료에서 모델을 적합하고 검증 자료에서 보정 후보를 선택한 뒤, 별도 테스트 자료에서 기준 모델과 선택 모델을 비교했다. 평가 지표는 구간 음의 로그우도, AUC, Brier score를 함께 사용했다.

확인한 결과
저장된 테스트 결과에서 5개 연령의 단순 평균 AUC는 기준 모델 0.6902에서 보정 모델 0.7072로 높아졌다. 평균 구간 음의 로그우도는 0.4840에서 0.4809로, 평균 Brier score는 0.09112에서 0.09051로 감소했다. 다만 일부 연령·지역·지표에서는 악화도 확인돼 전체 집단에 동일한 개선이 있었다고 설명하지 않았다.

이 평가는 공간 분할 검증이다. 인접 셀 사이의 완충거리나 미래 기간 검증까지 구현한 것은 아니며, 일부 입력의 회고적 구성도 남아 있다.

10. 예측 후처리: 현재 상태를 무시한 위험값 부여 방지

기술적 과제
모델의 생존시간을 그대로 사용하면 현재까지 사건이 없었다는 정보가 빠질 수 있었다. 이미 사건이 발생한 집단이나 추적이 중단된 집단에 동일한 미래 위험값을 부여하는 것도 해석상 문제가 있었다.

적용 기술과 처리
현재까지 사건이 없었다는 조건을 반영한 잔여 중앙시간과 향후 1개월·2개월 사건 확률을 계산했다. 사건 관측 전, 사건 관측 후, 추적 가능, 추적 중단 등의 상태를 분리해 예측 가능한 행에만 결과를 부여했다.

계산된 중앙시간에서 조건부 사건 확률이 50%가 되는지, 예측기간이 길어질수록 확률이 감소하지 않는지, 확률이 0~1에 있는지 검사했다. 관측기간 이후를 예측한 결과와 기존 설명변수 범위를 벗어난 시나리오는 별도 표시했다.

확인한 결과와 의미
12월 기준 예측 가능 집단 42,424개 격자·연령 조합에서 지역·연령별 잔여시간 하위 5%를 우선 점검 대상으로 선정했다. 선정 결과는 2,125개 격자·연령 조합, 중복 공간을 제거하면 975개 격자였다. 이 수치를 실제 위험 인원으로 바꾸어 설명하지 않았다.

11. 모델 설명과 후속 조치 연결: 추상적인 접근성 점수를 실제 시설로 분해

기술적 과제
접근성이 낮다는 점수만으로는 담당자가 어떤 시설을 확인해야 하는지 알기 어렵다. 모델과 별도로 주변 시설을 추천하면 학습에 사용한 접근성과 추천 근거가 서로 다른 계산이 될 수도 있었다.

적용 기술과 처리
모델에서 사용한 원시 접근성을 실제 시설별 기여도로 다시 분해했다. 시설 유형별 기여도 상위 3개 시설과 최단거리 시설을 함께 추출하고 시설명·주소·거리·기여 비중·자료 출처를 연결했다.

각 시설 기여도를 합한 값이 이전 단계의 접근성과 일치하는지 검사해, 모델 입력과 후속 시설 연결의 계산 일관성을 확인했다. 기존 실행에서는 12,433개 분해 행의 최대 절대 오차가 약 1.02e-16으로 기록됐다.

확인한 결과와 의미
우선 점검 대상에서 38,144개의 시설 후보 연결과 1,976개의 고유 후보 시설을 생성했다. 위험 점수에서 실제 위치를 가진 자원까지 근거를 추적할 수 있게 했다는 점이 핵심이다.

12. 규칙 기반 의사결정 지원: 서비스 자격과 실제 이용 가능성을 임의로 확정하지 않기

기술적 과제
격자 단위 분석으로 개인의 정확한 나이, 동의 여부, 돌봄 필요, 서비스 자격을 알 수 없었다. 인근 시설이 존재한다는 사실도 해당 시설이 특정 복지서비스를 제공하거나 즉시 수용할 수 있다는 의미는 아니었다.

적용 기술과 처리
위험 우선 대상의 접근성을 지역·연령별 기준 분포와 비교해 방문·이동 지원 검토 유형과 기존 자원 연결 검토 유형으로 나눴다. 서비스 카탈로그에는 지역, 연령 범위, 추가 확인 조건, 출처, 신청 진입점을 구조화했다.

규칙 엔진은 지역과 연령 조건, 대응 유형과 서비스 태그를 이용해 후보를 연결했다. 정확한 개인 나이가 필요한 경우와 동의·자격·수용 능력이 확인되지 않은 경우는 미확인 상태로 유지했다. 담당자가 확인할 질문과 후속 행동을 대응 카드에 포함했다.

구현 범위와 의미
조건부 서비스 후보 연결 5,764행을 생성했다. LLM이나 외부 API를 호출한 에이전트 실행은 수행하지 않았으며, RAG를 구현한 프로젝트로 설명하지 않는다. 이 부분의 실제 구현은 분석 결과를 구조화된 서비스 조건과 연결하는 규칙 기반 의사결정 지원이다.

13. 재현성 관리와 실제 실행 오류 대응

기술적 과제
단계별 스크립트가 늘어나면 입력·출력 경로가 섞이거나 이전 단계 결과와 다른 버전의 모델이 연결될 수 있었다. 통합 실행에서도 변수명 충돌과 선택 기능의 의존성 문제가 발생할 수 있었다.

적용 기술과 처리
주요 계산을 단계별 함수로 분리하고 공통 설정을 CFG로 모았다. 입력 위치와 새 결과 위치를 분리하고 실행 시각별 출력 폴더를 생성했다. 원자료부터 실행하는 rebuild와 기존 전처리를 재사용하는 replay를 구분해 실제로 다시 계산한 범위를 기록했다.

주요 입력 파일에는 SHA-256 해시를 기록하고, 실행 모드·처리 시간·모델 사양·검증 결과를 저장했다. 기존 기록에는 replay 모드에서 코드 셀 43개를 순차 실행해 α 탐색, AFT 재학습·평가, 우선순위, 시설 분해, 서비스 연결, 거점 시나리오, PDF 생성까지 통과한 내용이 있다. 원자료부터의 rebuild 전체 실행은 해당 검증에서 수행하지 않았다.

실제 확인된 실행 오류
사용자 환경에서 PDF 출력 단계의 reportlab 패키지가 없어 ModuleNotFoundError가 발생했다. 분석 계산과 PDF 출력을 RUN_PDF 옵션으로 분리한 구조를 통해, PDF가 필요하면 실행 커널에 reportlab을 설치하고 분석만 진행하면 RUN_PDF=False로 해당 단계를 건너뛸 수 있도록 대응 경로를 마련했다. 사용자 환경에서 설치 후 다시 실행한 성공 여부까지 확인된 것은 아니므로 오류가 완전히 해결됐다고 기록하지는 않는다.

기술적 의미
전체 파이프라인을 한 덩어리로 취급하지 않고 데이터 처리, 모델 계산, 검증, 지도·PDF 출력의 범위를 구분했다. 기존 입력의 변경 여부와 실제 재실행 범위를 추적할 수 있게 하고, 선택형 출력 의존성이 분석 실행을 막을 때 우회할 수 있는 구조를 갖췄다.

14. 포트폴리오용 기술 경험 요약

통신·카드·건물·시설 자료를 50m 격자로 통합하고, 유사한 환경의 비교 집단을 이용해 활동 잔차를 산출했다. 시설 접근성은 거리 기반 중력 지표로 구성했으며, 주변 활동 특성에 따른 α 보정 후보 13개를 비교했다. 월별 관측의 불확실성과 결측을 반영한 구간 중도절단 라벨을 만들고 Weibull AFT를 적용했다.

공간적으로 가까운 자료가 학습과 평가에 섞이는 위험을 줄이기 위해 500m 공간 셀 단위 검증을 구성했다. 별도 테스트에서 기준 모델과 보정 모델을 비교하고, 평균 개선뿐 아니라 일부 집단에서의 악화도 확인했다. 이후 조건부 위험과 우선순위를 산출하고, 모델의 접근성을 시설별 기여도로 재현해 실제 자원 후보와 연결했다.

기술적으로 중점을 둔 부분은 모델의 복잡성보다 데이터 정합성, 관측과 대리변수의 구분, 결측·중도절단 처리, 수치 안정성, 공간 평가, 단계 간 계산 일관성, 실행 이력 추적이었다. 분석값을 실제 개인 진단이나 정책 효과로 확대 해석하지 않으면서, 담당자가 검토할 수 있는 근거와 조치 후보를 함께 제공하도록 구현했다.
